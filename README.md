# FlashDeck

오프라인으로 동작하는 플래시카드 암기 앱 (PWA). 서버·로그인·클라우드 동기화가 없고, 덱과 진행 기록은 각 기기의 브라우저(IndexedDB)에만 저장됩니다.

- 호스팅되는 앱은 **빈 껍데기**입니다. 문제 덱은 기기마다 파일로 가져옵니다. 덱 파일은 이 저장소에 커밋하지 마세요 (`.gitignore`에 `decks/`, `*.deck.json`, `deck_*.json`, `*backup*.json`, `*.csv`가 들어 있습니다).
- 빌드 과정이 없는 정적 파일(HTML/CSS/ES 모듈)이라 어느 정적 호스트에도 올릴 수 있습니다. 외부 CDN을 쓰지 않아 첫 로드 이후엔 완전 오프라인입니다.

## 쓰는 법

1. 설정 → **덱 파일 가져오기**에서 `.json`(flashdeck) 또는 `.csv` 선택. 형식은 [IMPORT_FORMAT.md](IMPORT_FORMAT.md).
2. 홈에서 카테고리를 누르면 그 주제만 학습합니다. 순서대로/랜덤, 오늘 복습/전체는 홈 위쪽에서 고릅니다.
3. 카드를 탭하면 정답이 열리고, **못 외움 / 애매함 / 외움**으로 평가합니다.
4. **오답노트**에는 못 외움 + 애매함 카드만 모입니다. 카드를 누르면 그 카드부터, 위 버튼을 누르면 처음부터 오답만 이어서 학습합니다. “외움”으로 평가하면 오답노트에서 빠집니다.
5. 설정 → **백업 내보내기**로 덱과 진행 기록을 JSON으로 저장해 두세요. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 필요합니다.

키보드: `Space` 정답 공개 · `1/2/3` 평가 · `← →` 이전/건너뛰기 · `Esc` 나가기.

복습 주기(못 외움=매 세션, 애매함=3일, 외움=14일)와 세션 안 재등장 규칙은 [js/sched.js](js/sched.js) 맨 위 상수로 조정합니다. 세션 안에서 못 외움은 최대 2번, 애매함은 1번까지만 되돌아오고, 위치는 5~8장 뒤부터 세션 끝까지 무작위입니다. 그래서 틀린 카드에 갇히지 않고 뒤쪽 카드까지 진행됩니다.

## 설치 (홈 화면에 추가)

| 기기 | 방법 |
| --- | --- |
| iPhone / iPad | Safari로 사이트를 열고 공유 버튼 → **홈 화면에 추가**. 홈 화면 아이콘으로 열어야 앱처럼 동작합니다. |
| Android | Chrome 메뉴 → **앱 설치** (또는 홈 화면에 추가). |
| Mac | Safari: 파일 → **Dock에 추가**. Chrome: 주소창 오른쪽 설치 아이콘. |

설치한 뒤 한 번 온라인으로 열어 두면 이후엔 비행기 모드에서도 열립니다. 각 기기에서 덱 파일을 따로 가져와야 합니다 (기기 간 자동 동기화 없음).

## 데이터 모델 (나중에 플러터 이식 가능하도록 기기 독립적인 JSON)

- 덱: `{ id, title, language, cards[] }` — 카드 `id`는 덱 파일에 들어 있는 안정적인 문자열
- 진행: `{ key: "<deckId>|<cardId>", rating(0 없음/1 못 외움/2 애매/3 외움), last, count, due }`
- 같은 제목의 덱을 다시 가져오면 같은 덱으로 취급해 카드만 갱신하고, 카드 `id`가 같은 진행 기록은 유지합니다.
